# K.A.I.R.O.

> **168 HOURS. NOTHING MORE. NOTHING LESS.**

K.A.I.R.O. is not a to-do list. It is a brutalist Life OS and personal command center engineered for absolute self-accountability.

Built on the Neo-Pastel Editorial Bento Design System. Zero friction. Maximum aura.

---

## ⚡ CORE TENETS

- **The Ledger:** You get 168 hours a week. Where are they going? K.A.I.R.O. demands answers.
- **Cost of Delay:** Procrastination mapped directly to financial loss.
- **Deep Work Telemetry:** Live WakaTime, GitHub hooks, and Focus Modes integrated at the core.
- **Automation Node:** Background broadcast receivers silently log your expenses from Ivy Wallet.
- **Energy Gauntlet:** Your active peaks, quantified. Complete them, or fail the day.

---

## 🛠️ THE STACK

- **Engine:** Flutter (Material 3 UI).
- **Brain:** Isar (On-Device DB. Fast. Offline. Brutal).
- **State:** Riverpod.
- **Integration:** Android Native AppWidgets & MethodChannels for absolute system control (Digital Wellbeing, DND).

---

## 🚀 INITIATE

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run --release
```
